This website

This static website does not use advertising, analytics, tracking pixels, accounts, or cookies. It does not collect information through forms.

Theme preference

At the start of a browser session, the site randomly selects one of six visual themes. The selected theme is stored in sessionStorage so navigation remains consistent and so your dropdown choice lasts for the current visit. Session storage is scoped to this site and browser tab session; it is not transmitted to Quasar Labs and is not designed to persist indefinitely.

If JavaScript or browser storage is unavailable, the site falls back to the dark Obsidian theme and remains fully readable and navigable.

Hosting

The site is hosted by GitHub Pages. GitHub may process technical information such as IP addresses and request logs to provide and secure its service. See GitHub’s Privacy Statement for details.

External destinations

Links to GitHub, Gumroad, L’IRC’in, and the Cuspr product site leave this parent website. Those destinations have their own privacy practices. Review their policies before providing personal or payment information.

Email

If you email Quasar Labs, the message and your address are used to respond to your inquiry. Do not send secrets, passwords, license keys, or sensitive personal information by email.

Questions

Privacy questions can be sent to quasarlabs-inc@outlook.com.
