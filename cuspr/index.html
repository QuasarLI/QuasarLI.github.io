Installable does not mean native Android

Cuspr installs on Android through the browser as a Progressive Web App. No native Android APK is claimed or linked.

Windows release integrity

Windows x64 release artifacts can carry SHA-256 checksums and keyless Sigstore provenance. Sigstore is not Windows Authenticode signing and does not promise Microsoft SmartScreen reputation.

Verified destinations

The marketing site, live app, product facts, and v0.4 source snapshot are canonical. Direct build URLs are intentionally omitted until public assets are independently verified.
