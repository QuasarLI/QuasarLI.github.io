Choose the connection

Go direct by HDMI. Or stream over your LAN.

Direct HDMI / every tier

Your PC, connected to your TV

Connect the Windows PC's supported HDMI output to your TV. PixelBridge lists active displays and opens native Windows projection, display, supported resolution/refresh, and sound-output controls. These are guided settings, not automatic output or TV firmware control. Keep a keyboard available; Win+P then PC screen only is the recovery route.

HDMI removes the local Sunshine encode/decode path. Xbox Cloud Gaming and GeForce NOW still have their provider and internet latency. The controller stays paired directly to the PC; HDMI-CEC, HDR, and particular display modes are not guaranteed.

Local-network streaming / every tier

Sunshine host, Moonlight client

Sunshine is not included in any edition. Open its official upstream release page for independent download, verification and installation, reuse your configured host, or defer to HDMI/this PC. PixelBridge never downloads or invokes a Sunshine installer; it can start or reuse your user-configured host. Moonlight is also installed separately.

Guided LAN onboarding helps you choose a private home-network address and check the local host response. That response is not proof of receiver pairing, encoding, game compatibility, or TV audio. PixelBridge does not read Sunshine's host configuration, credentials, certificates, or pairing state.

No router WAN port forwarding or UPnP is required for this LAN setup. Optional firewall guidance previews the executable, address, subnet, ports, and Private profile before consent and Windows elevation; it does not open the host administration port or configure your router. PixelBridge does not automatically change VPN settings or disable security tools.

Saved TV hardware checklists / every tier

Save your own route, transmitter/receiver model, TV input, cable/length, power and vendor specifications, then explicitly choose the saved TV path. These are user-designated checklists, not a tested-model list or hardware detection/control.

  • Direct HDMI: supported PC HDMI output to your TV.
  • Wired Moonlight: an Ethernet LAN with a supported Sunshine/Moonlight receiver. TV Ethernet alone cannot decode the video.
  • Matched HDMI extender / HDBaseT: a compatible transmitter and receiver with their dedicated, vendor-rated category cable. This is not ordinary Ethernet; do not use a router/switch unless that exact model explicitly supports it.
  • AV-over-IP: an explicitly supported transmitter/receiver pair with the vendor-specified topology, switch, bandwidth and power.

Passive RJ45-to-HDMI adapters are not a guaranteed substitute. Check the exact matched hardware's cable limits, HDCP, resolution/refresh, HDR, audio and latency specifications. PixelBridge makes no hardware purchases and performs no automatic adapter, hotspot, router or TV-network changes.

Acceptance testing is still incomplete: real service/cloud use, physical controller menus, new emulator/controller gameplay, TV hardware/HDMI display/audio, and clean-PC Sunshine/Moonlight pairing have not been verified. Earlier Xbox streaming success with the predecessor app does not establish those results. PixelBridge does not promise zero lag, lower cloud latency, higher FPS, or support for every TV, streaming stick, controller, HDMI mode, or game.

Native profiles / every tier

Standard profiles and import/export stay free.

The five standard .rmp remaps and common XInput .cfg bindings target RetroArch 1.21.0 with its Windows XInput joypad driver. Pair your controller directly to the PC. Import or export these standard native files in any edition without paid activation.

Launcher menu navigation / every tier

The saved Controller menu navigation on/off checkbox stays visible above every tab. Mouse and keyboard always remain available, including when controller navigation is off. With an XInput controller paired to the PC, D-pad/left stick moves focus and scrolls, A activates/toggles/cycles choices, and LB/RB switches tabs. B, like Esc, closes only PixelBridge, not Sunshine, a browser or a game.

This controls only PixelBridge's foreground main window. It yields to background apps, minimized windows, dialogs and busy actions: no external browser, TV or Windows remote control, global input hook or exclusive controller capture. Text entry, remap grids, dialogs and sign-in still need keyboard/mouse. This menu option does not change game mappings or establish physical controller/TV compatibility.

Verify a Free ZIP on Windows before launch

Install trusted cosign v3 using official Sigstore guidance. Download the selected ZIP, its ZIP and EXE bundles, and all three metadata files with their bundles from the release links above into one folder. Do not trust a cosign binary just because it sits beside an app download. Run PowerShell in that folder and stop on any failure.

$ErrorActionPreference = 'Stop'
$identity = 'https://github.com/QuasarLI/PixelBridge-Distribution/.github/workflows/release.yml@refs/heads/main'
$issuer = 'https://token.actions.githubusercontent.com'
$workflow = 'd3eaad89d4470deb4cbf34750d28ac2c42b54132'
$zip = 'PixelBridge-v1.3.0-Free-win-x64.zip'
foreach ($name in @($zip, 'release-manifest.json', 'provenance.json', 'SHA256SUMS')) {
    cosign verify-blob --bundle "$name.sigstore.json" --certificate-identity $identity --certificate-oidc-issuer $issuer --certificate-github-workflow-sha $workflow $name
    if ($LASTEXITCODE -ne 0) { throw "Signature verification failed: $name" }
}
$manifest = Get-Content -LiteralPath '.\release-manifest.json' -Raw | ConvertFrom-Json
if ($manifest.schema_version -ne 1 -or $manifest.product -cne 'PixelBridge' -or $manifest.version -cne '1.3.0' -or $manifest.distribution_mode -cne 'nonbundled') {
    throw 'Unexpected manifest product/version/schema/distribution mode'
}
$provenance = Get-Content -LiteralPath '.\provenance.json' -Raw | ConvertFrom-Json
if ($provenance.schema_version -ne 1 -or $provenance.product -cne 'PixelBridge' -or $provenance.version -cne '1.3.0' -or $provenance.distribution_mode -cne 'nonbundled') {
    throw 'Unexpected provenance product/version/schema/distribution mode'
}
$manifestHash = (Get-FileHash -LiteralPath '.\release-manifest.json' -Algorithm SHA256).Hash.ToLowerInvariant()
if ($manifestHash -cne 'a82a2af9313565e6d00e8f96fc1986b7f3dbbf217d9035c79c5d4a1dde778ef0' -or $provenance.manifest_sha256 -cne $manifestHash -or $provenance.source_commit -cne '5f74e07189f62540b6b4e8df0236d0c5ba37370d' -or $manifest.source_commit -cne $provenance.source_commit -or $provenance.distribution_commit -cne $workflow -or $provenance.workflow_identity -cne $identity -or $provenance.oidc_issuer -cne $issuer -or $provenance.workflow_run -cne 'https://github.com/QuasarLI/PixelBridge-Distribution/actions/runs/40428106814/attempts/1') {
    throw 'Signed provenance does not match exact release pins'
}
$entry = @($manifest.artifacts | Where-Object { $_.file -ceq $zip })
if ($entry.Count -ne 1) { throw 'Missing or duplicate ZIP in manifest' }
$file = Get-Item -LiteralPath $zip
$hash = (Get-FileHash -LiteralPath $zip -Algorithm SHA256).Hash.ToLowerInvariant()
if ($hash -cne $entry[0].sha256 -or $file.Length -ne $entry[0].size_bytes) {
    throw 'ZIP bytes do not match signed manifest'
}
if (@(Get-Content -LiteralPath '.\SHA256SUMS' | Where-Object { $_ -ceq "$hash  $zip" }).Count -ne 1) {
    throw 'ZIP checksum does not match signed SHA256SUMS'
}
