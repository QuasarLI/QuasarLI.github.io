CineDock / support groundwork

Clear routes. No premature release promises.

CineDock is in private development. There is no public installer, public source offering, customer release, or announced release date.

General questions

The existing Quasar Labs general inquiry address is quasarlabs-inc@outlook.com. Name CineDock in your subject. A monitored CineDock-specific support, privacy, and deletion contact has not yet been confirmed; no response-time or deletion-service commitment is made here.

Do not send Google passwords, OAuth client JSON files, access or refresh tokens, authorization codes, browser profiles, private media, or unredacted logs. This website does not offer Google sign-in and will not ask you to upload those items.

Development feedback

If you already have an owner-provided preview, keep using its existing private feedback route. Include the build identifier supplied with that preview, Windows version, reproduction steps, and the observed and expected result. Remove account details, sensitive filenames, network addresses, and credentials before sharing diagnostics. Do not publish private preview files in a public issue.

Google access and local data

Read the development data-use notes and deletion and revocation distinctions. Removing account access does not delete downloaded originals, converted outputs, or every local artifact.

Remaining owner and release steps

  1. Approve the responsible publisher identity, monitored contact, final data/processor inventory, retention decisions, and usable deletion instructions.
  2. Finalize matching public homepage, privacy policy, and any required terms; confirm production domain ownership and production Google Desktop-client configuration.
  3. Complete the appropriate Google branding and restricted Drive-scope review, with any assessment Google requires. A published website is not approval.
  4. Complete real-account Drive browsing/playback and owner-attended optional integration checks; validate the intended Windows, controller, physical-device, and remote-host boundaries.
  5. Review public distribution and third-party notices before offering any public package. No private preview is a public download.

These are release prerequisites, not a launch schedule. Browser/caching research is separate from a decision to ship it; no Google-login bypass is offered.
