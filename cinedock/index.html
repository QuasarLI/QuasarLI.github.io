The development app

A calmer way into your collection.

These capabilities describe the private development app, not a generally available or universally tested product.

Library

Local and mounted media

Browse your own local folders and network libraries mounted on your Windows PC. You supply the media and access rights.

Playback

Built around libmpv

A media-focused playback foundation, with compatibility dependent on the file, codec, device, and runtime.

Navigation

Readable from the sofa

Keyboard and mouse navigation with opt-in Xbox navigation. Physical controller and remote compatibility still need separate testing.

Atmosphere

Make room for quiet

Ambient screensavers and original console-inspired visuals, without claiming affiliation with another media-center or console brand.

Optional, with clear boundaries

More possibilities. Separate checks.

Cloud / under evaluation

Google Drive

The private app opens the external system browser for authorization; sign-in there currently needs keyboard and mouse. Successful sign-in alone does not establish complete library browsing, streaming, or Google OAuth approval. Google account access is not available on this website.

Conversion / optional

Saved high-frame-rate media

Ordinary lightweight playback is the default. Optional saved-HFR conversion uses a separately installed and licensed SVPcode companion, not verified in-app SVP automation or real-time smoothing. Source and device compatibility still need checking.

Host setup / optional

Sunshine and Moonlight

Optional host-setup integration remains under evaluation. End-to-end attended runtime acceptance is incomplete; receiver pairing, remote hosts, physical devices, and Windows 10 need distinct checks.

Research is not a shipped feature: alternative browser sign-in and library caching approaches are being assessed separately. This page does not offer an embedded-login workaround, bypass Google authorization, or promise offline cloud playback.

A separate, user-managed local-file route

Files exposed by Google's own Drive for desktop client or downloaded through a standard browser are another workflow under evaluation. That filesystem-only route does not need a CineDock API grant, but it is not native cloud integration or an authentication bypass. Connected-client, local storage, seeking, offline availability, and conversion compatibility still need checks. Sync changes or deletions can affect cloud copies; review Google's stream and mirror guidance before changing your setup.
