Productivity · Windows

TaskForge

Stable + beta

TaskForge brings system health information and practical controls into one desktop utility. The v2.2 beta explains live CPU, memory, commit pressure, and top processes; it can also request native Windows battery and energy reports without changing system settings.

Choose deliberately: v2.1.0 is the latest stable release. v2.2.0-beta.1 is a prerelease for early evaluation and may still contain unfinished behavior.

Backup · Windows + Android

Quasar

v0.4.0

Quasar is a local backup tool offered as Free, Free with Ads, Supporter, and Pro editions. Each edition has an explicit monthly limit, and every platform-and-edition build is distributed as a versioned ZIP with checksums and Sigstore verification material.

Know the boundary: monthly upload limits are edition usage allowances, not hosted storage. Users choose and manage their own backup destinations.
